# HKG 超低速自動變換車道（實驗功能）

分支：`TonyBinheWu/sunnypilot:hkg-enhanced`

這個獨立開關讓相容的 Hyundai／Kia／Genesis（HKG）CAN-FD 扭力控制車型，在 0–5 km/h 由駕駛打單側方向燈後，請求系統自動變換到相鄰車道。駕駛仍是確認前方空間、側後方車流、目標車道與車身淨空的最終依據。

控制器與 Panda safety 來自固定的 `TonyBinheWu/opendbc@a4c49e28e42d367bb26d490ffdbbb88334c38979`。

## 開啟方式

在裝置的 **Settings → Steering → Customize Lane Change → HKG 超低速自動變換車道（實驗功能）** 開啟。

- 預設關閉，只能在非行車狀態與已辨識到相容 HKG 車型時調整。
- 於下次啟動行車系統時生效。
- 與 `AutoLaneChangeTimer` 及 `HkgLowSpeedTorque` 分開設定；一般車速的變換車道計時不會改變。
- 不相容車型即使手動寫入參數，也不會設定控制器或 Panda safety 的功能旗標。

## 每次請求的條件

只有單側方向燈由關閉變成開啟時，才會建立一次超低速變換車道請求。建立與執行時會檢查：

- 橫向控制有效。
- 車速介於 0–5 km/h。
- 模型訊息有效。
- 模型第一前車的機率低於 0.5 時視為未偵測到前車；機率至少 0.5 時，模型前車縱向距離必須至少 5.0 公尺。
- 方向燈側的車輛盲區訊號沒有偵測到車輛。
- 只有一側方向燈開啟。

踩住煞車時請求會停在等待狀態；放開煞車且條件持續成立 0.5 秒後才開始轉向。開始轉向後，踩煞車、取消方向燈、盲區出現車輛、模型失效或前車距離低於門檻都會中止這次動作。持續亮著同一方向燈不會觸發第二次變換；必須先取消，再重新打方向燈。

模型的「未偵測到前車」只代表沒有超過目前機率門檻的目標，不能證明路徑沒有障礙物。5 公尺是此次試作的固定程式門檻，也不是車身斜向切出必然無碰撞的保證。

## 動態轉向上限

400 是轉向 CAN 指令的絕對值上限，不是 Nm。只有模型端已進入本次超低速變換車道、`controlsd` 再次通過條件檢查，且 Panda 收到近期單側實體方向燈訊號時，控制器才可使用新增區間。

| 車速 | `HkgLowSpeedTorque` 關閉 | `HkgLowSpeedTorque` 開啟 |
| --- | ---: | ---: |
| 0–2 km/h | 400 | 400 |
| 2–5 km/h | 400 線性降至 270 | 400 線性降至 350 |
| 5 km/h 以上 | 270 | 沿用既有 350→270 動態曲線 |

車速跨過曲線、條件失效或動作取消時，CarController 依既有每幀下降速率回落。Panda 允許超出新上限的既有指令單調下降，但不允許保持或增加，避免退出瞬間因硬切上限而拒絕整個降扭力序列。

Panda 以 CAN 輪速、煞車與實體方向燈獨立檢查 400 上限；方向燈燈泡訊號會閃爍，因此 safety 只保留 1.2 秒的近期單側訊號。Panda 收不到模型資料，模型有效性、前車距離與實際變換車道狀態由 modeld、controlsd 與 CarController 的連續閘門負責。

## 試車記錄

先在可控場地由 0 km/h 開始，保持可立即煞停與接管。每次只測一個方向燈請求，確認：

- 無前車，以及模型顯示前車距離略高於／低於 5 公尺時的放行差異。
- 踩住煞車時不開始，放開後延遲 0.5 秒。
- 取消方向燈、踩煞車及方向燈側盲區警示會中止。
- 0、2、接近 5 與超過 5 km/h 的 `torqueOutputCan` 上限與平滑回落。
- 同一方向燈持續亮著時只執行一次。

軟體測試不能驗證 EV6 或其他 HKG 車型的 EPS 物理輸出、輪胎與路面狀況、模型車身掃掠路徑或實際碰撞淨空。道路使用前仍需用裝置記錄確認模型前車距離、變道狀態、車速、方向燈與輸出扭力是否符合上述條件。
